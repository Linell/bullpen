# Bullpen

A small app for displaying baseball data. Built with Next.js, Tailwind CSS v4, and [neobrutalism components](https://www.neobrutalism.dev/docs).

## Development

```bash
pnpm install
pnpm dev
```

## Adding components

Each component page on neobrutalism.dev gives a registry command, e.g.:

```bash
pnpm dlx shadcn@latest add https://neobrutalism.dev/r/card.json
```

Components land in `components/ui/`.
